i have been using the last 2 weeks to relax and get back settled to home. Fiddling about with Android and on my ongoing projects. I bought an encasing for a external HDD 3.5" bay and am within the process of creating a image file for my server data.

I also been taking a look at RPCS3. Nice to go PlayStation 3 emulator. Works just fine on my system. Besides that I got not much to report currently.

Started experimenting with getting certain games to work such as Marvel Spider Man and or Call of Duty (2003) & F1 2012.

Successfully Call of Duty had to be run using Proton 5.13-6 + this set of launch parameters

_GL_ExtensionStringVersion=17700 %command% +set r_mode -1 +set r_customheight 1080 +set r_customwidth 1920 +set cg_fov 80 +set cg_drawfps 0

otherwise I would get color banding with Proton and the mouse cursor ingame would freak out weird for a game that ran just fine using wine.

F1 2012. I could only get to properly launch using WineSteam instealled via Wine Tricks & Lutris. There still be visual artifacts but the game would run just fine on my machine.

Marvel Spider Man installed via script ran fine using Glorious Eggrols v10.8 of Proton.
